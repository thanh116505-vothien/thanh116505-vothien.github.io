Mảng Kỹ Thuật — Technical Domains

Đọc cấu trúc file, làm chủ luồng thực thi.

Phân tích container nhị phân, giải mã archive nén độc quyền và xây dựng toolchain Việt hóa giữ nguyên vẹn 100% biến logic.

  • Trích xuất & đóng gói asset trên Unity, Ren'Py, RPG Maker, Kirikiri
  • Chỉnh sửa Font Texture, Signed Distance Field (SDF) & TextMeshPro tiếng Việt có dấu
  • Giữ nguyên 100% control tag (<color>, <b>), regex và biến logic ({0}, %s)
  • Kiểm thử encoding, phân tích bytecode script và logic hội thoại

Can thiệp logic gameplay bằng script hook và plugin, kết hợp đo đạc FPS profiling và tối ưu bộ nhớ.

  • Viết custom tool, launcher và script mở rộng tính năng game
  • Phân tích điểm nghẽn hiệu năng, FPS profiling và bắt rò rỉ bộ nhớ
  • Đánh giá render behavior và debug xung đột mod giữa các phiên bản

Triển khai Dedicated Server game ổn định, tối ưu networking độ trễ thấp và thiết lập sao lưu dữ liệu tự động.

  • Cấu hình Dedicated Server, routing mạng và giảm thiểu độ trễ (ping)
  • Quản trị cơ sở dữ liệu, tự động hóa backup và monitor tài nguyên CPU/RAM
  • Xử lý sự cố mạng, bảo đảm uptime và khôi phục dữ liệu nhanh chóng

Kiểm thử chức năng thực tế trên uTest, tái hiện bug với bằng chứng xác thực và rà soát an toàn logic hệ thống.

AI Engineering & Tự Động Hóa

Không chỉ viết prompt — thiết kế trọn bộ pipeline tự động hóa.

Không dựa vào prompt hên xui. Toàn bộ quy trình được khóa chặt bằng schema JSON, ngữ cảnh phân tầng, bảng glossary đồng bộ và script tự động validate để đảm bảo bản dịch chính xác, không bao giờ mất thẻ nhúng hay biến format.

Stage 01: Source Asset Extraction & Sanitization

Trích xuất dữ liệu chuỗi hội thoại thô từ container nhị phân của engine, tách biệt cấu trúc JSON keys với văn bản hiển thị và ghi nhận metadata người nói.

INPUT: Raw binary archives (.assets, .rpa) ➔ OUTPUT: Standardized AST / JSON Key-Value
1. Structured Output
Khóa chặt output của LLM theo đúng cấu trúc JSON/YAML để code parse được ngay, kết hợp few-shot examples và schema validation nghiêm ngặt.
2. Prompt Chaining
Chia nhỏ quy trình thành chuỗi vi tác vụ: phân tích thể loại ➔ dịch thuật ngữ ➔ chuẩn hóa văn phong ➔ kiểm tra cú pháp tag.
3. Model Context Protocol
Ứng dụng giao thức MCP, liên kết AI Agent trực tiếp với GitHub, file hệ thống và database để tự động kiểm thử và deploy.
4. Persona Naturalization
Tự nhiên hóa văn phong đối thoại: gọt giũa câu từ mềm mại, giữ đúng khẩu khí kiếm hiệp, giang hồ hoặc cá tính riêng của từng nhân vật.
