Chiến Lược Thi Thực Hành Java Trên IntelliJ IDEA

Được thi trên IntelliJ nghĩa là có gợi ý cú pháp và tự động sinh mã. Đừng học vẹt từng dòng code! Hãy nắm vững 6 khung sườn cốt lõi dưới đây, đi thi chỉ cần gõ đúng sườn và dùng phím tắt IntelliJ là lấy trọn điểm.

1. Căn Bản, Toán Tử & I/O
Bẫy trôi lệnh & Format
// KHUNG NHẬP XUẤT AN TOÀN Scanner sc = new Scanner(System.in); int n = sc.nextInt(); sc.nextLine(); // BẮT BUỘC nuốt ký tự '\n' nếu sau đó đọc chuỗi! String s = sc.nextLine(); // Format in ra màn hình System.out.printf("%.2f%n", result); // 2 chữ số thập phân System.out.printf("%s\t%s%n", col1, col2); // Cách nhau bởi Tab
  • ⚠ Chia số thực: Bắt buộc viết 9.0 / 5 hoặc (double)a / b, nếu viết 9/5 sẽ ra 1!
  • ⚠ In dấu % trong printf: Phải viết %% (ví dụ: %.2f%%).
2. Toán Học & Số Học
Euclid, SNT, Đảo số
// 1. USCLN EUCLID (3 dòng): while (b != 0) { int t = b; b = a % b; a = t; } return a; // 2. KIỂM TRA SNT: if (n < 2) return false; for (int i = 2; i * i <= n; i++) if (n % i == 0) return false; return true; // 3. ĐẢO SỐ NGUYÊN (Tách chữ số): while (n > 0) { rev = rev * 10 + n % 10; n /= 10; }
  • ⚠ GCD với số âm: Dùng Math.abs(a) trước khi chạy.
  • ⚠ Số hoàn hảo: Ước thực sự chỉ duyệt đến n / 2.
  • ⚠ Đổi cơ số: Dùng sẵn Integer.toBinaryString(n), toHexString(n).
3. Mảng 1D & Thống Kê
Tần suất & Sắp xếp
// MẢNG ĐẾM TẦN SUẤT ĐIỂM (0 đến 10): int[] tk = new int[11]; for (int i = 0; i < n; i++) tk[sc.nextInt()]++; // TÍNH TỈ LỆ %: double tile = 100.0 * tk[i] / n; // Nhân 100.0 TRƯỚC! // SẮP XẾP MẢNG TĂNG DẦN: Arrays.sort(arr);
  • ⚠ Lỗi chia nguyên khi tính %: tk[i] / n * 100 sẽ ra 0! Bắt buộc 100.0 * tk[i] / n.
  • ⚠ Tìm min 1 & min 2 (Marathon): Khi gán min 1 mới, phải chuyển min 1 cũ cho min 2 trước.
4. Mảng 2D & Ma Trận
Căn lề %8.2f & Phép toán
// NHẬP VÀ IN MA TRẬN CĂN LỀ: double[][] a = new double[n][m]; for (int i = 0; i < n; i++) { for (int j = 0; j < m; j++) { System.out.printf("%8.2f", a[i][j]); // Đúng 8 ô căn phải } System.out.println(); // Xuống dòng mỗi hàng }
  • ⚠ Ma trận chữ nhật: n hàng (i), m cột (j). Đừng nhầm lẫn index i và j.
  • ⚠ Đi thi nên tách 3 hàm: inputMatrix, sumMatrix, printMatrix.
5. Chuỗi & Collections (Map/Set)
Tách từ & Đếm số lần
// TÁCH TỪ CHUẨN: String[] words = line.trim().split("\\s+"); // ĐẾM TẦN SUẤT BẰNG MAP (1 dòng): Map map = new TreeMap<>(); // Tự xếp A-Z for (String w : words) map.put(w, map.getOrDefault(w, 0) + 1); // LỌC TỪ TRÙNG BẰNG SET: Set set = new TreeSet<>(Arrays.asList(words));
  • ⚠ So sánh chuỗi trong Java: CẤM dùng ==, BẮT BUỘC dùng str1.equals(str2)!
  • ⚠ TreeMap và TreeSet tự động sắp xếp các từ tăng dần theo từ điển A-Z.
6. Lập Trình OOP (Trọng Tâm)
Kế thừa, Sinh code IntelliJ
// QUY TẮC VÀNG VIẾT CLASS NHANH TRÊN INTELLIJ: // 1. Khai báo thuộc tính private // 2. Ấn Alt + Insert -> Sinh Constructor, Getter, Setter, toString // 3. Kế thừa: class Square extends Rectangle { public Square(double side) { super(side, side); } } // 4. Sắp xếp với Comparable: class Book implements Comparable { public int compareTo(Book o) { return Double.compare(this.price, o.price); } }
  • ⚠ Lớp con gọi constructor cha: super(param...) phải nằm ở dòng lệnh ĐẦU TIÊN.
  • ⚠ Thuộc tính static (SavingsAccount): Dùng ClassName.field, không dùng this.field.

Phím Tắt Vàng IntelliJ IDEA Đi Thi Thực Hành

Tận dụng triệt để IDE để code nhanh gấp 5 lần so với gõ tay, không bao giờ lo sai cú pháp hay quên cú pháp.

Live Templates (Gõ tắt sinh code)
Gõ tắt Mã tự động sinh ra Mô tả
psvm + Tab public static void main(String[] args) Hàm main chính
sout + Tab System.out.println(); In xuống dòng
souf + Tab System.out.printf(""); In định dạng
fori + Tab for (int i = 0; i < ...; i++) Vòng lặp for index
iter + Tab for (Type item : collection) Vòng lặp foreach
Phím Tắt Tự Sinh Mã Tối Thượng (Tự viết cả Class)
Phím tắt Chức năng cực đỉnh
Alt + Insert
(Fn + Alt + Insert)		 Mở bảng Generate: Tự động sinh Constructor, Getter and Setter, toString(), equals and hashCode(). (Khai báo 5 biến xong bấm phím này là xong nguyên bài OOP trong 3 giây!)
Ctrl + Alt + L Reformat Code: Tự căn chỉnh thụt lề, dấu cách, ngoặc nhọn cực chuẩn và đẹp mắt ngay lập tức.
Alt + Enter Show Intention Actions / Quick Fix: Sửa lỗi nhanh, tự import thư viện thiếu, tự implement methods của interface (Comparable...).
Ctrl + / Bật / tắt comment dòng code hiện tại.
Shift + F10 Chạy chương trình (Run Main).
