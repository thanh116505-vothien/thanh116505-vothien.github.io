## 🏛️ Giới thiệu

Website portfolio cá nhân của **Vô Thiên (Trần Viết Thành)**, được thiết kế theo ngôn ngữ mỹ thuật **"Từ Đồng Đến Mã" (From Bronze to Code)** — giao thoa giữa hoa văn mỹ thuật Việt cổ (trống đồng Đông Sơn, họa tiết Lý – Trần, vàng quỳ, sơn mài) và công nghệ số hiện đại (circuit board, terminal HUD, cybernetics).

Toàn bộ hệ thống giao diện, tương tác, SVG vectors và hiệu ứng chuyển động đều được xây dựng nguyên bản, không dùng thư viện ngoài nặng nề, tối ưu tải trang cực nhanh và chạy trực tiếp trên **GitHub Pages**.

## 🛠️ Chuyên môn & Dự án
- **Game Localization & Tooling:** Trích xuất, dịch thuật tự động kết hợp glossaries chuyên ngành, đóng gói asset binary.
- **Reverse Engineering & Modding:** Phân tích giao thức mạng, unpack format độc quyền, viết hook engine & cheat detection testing.
- **Dedicated Game Servers & Infrastructure:** Cấu hình headless server Linux, CI/CD, auto-backup, giám sát tài nguyên.
- **AI Engineering & Pipeline:** Tích hợp LLM API, prompt engineering, agentic workflow, tối ưu hóa suy luận nội bộ.
- **QA Automation & Security:** Scripting kiểm thử tự động, vulnerability assessment cho web/hệ thống nhỏ.

## 🚀 Công nghệ sử dụng
- **Frontend:** Semantic HTML5, Custom CSS Tokens (Gold, Crimson, Bronze, Jade, Terminal Cyan), Vanilla Modern JavaScript (ES6+).
- **Vectors & UI Assets:** 100% Native Inline & Standalone SVGs tự thiết kế theo chuẩn tỷ lệ Đông Sơn và Cyber Circuit.
- **Hosting:** GitHub Pages (Root domain: `thanh116505-vothien.github.io`).
